## Excluded from the proposed payload

Original implementation and setup scripts; notebooks and prompts; raw, processed, cached, synthetic, and split data; transcripts and audio; checkpoints and serialized models; row-level predictions; experiment plots and numerical results; source manifests and download logs; cached websites and papers; private review records; credentials and environment files; local filesystem paths; the original archive; and existing Git history/configuration.

The local review directory and the original project are outside the public folder and must remain excluded. The public `.gitignore` uses an explicit file allowlist as a guard against accidental staging. Ignore rules can be overridden and are not a substitute for checking the actual publication payload.

## Why source code is excluded

The local project has mixed provenance, begins from a supplied archive, and lacks a project-wide license and a commit history that could help attribute changes. This is an evidence gap, not a conclusion that the owner cannot legally publish their own work. It means the requested condition—clearly established publication rights for included code—has not yet been met.

## Unresolved publication decisions

| Issue | Current treatment | Required resolution |
|---|---|---|
| Code ownership and licensing | No source code included | Confirm archive origins, contributor rights, and any third-party notices before a future code release |
| Competition or institutional obligations | No submission documents or competition affiliation claimed | Confirm exact rules on public disclosure, confidentiality, IP, AI assistance, and sponsor rights; these may also affect architecture descriptions |
| Personal contribution attribution | Limited to documented direction and requirements | Owner reviews the attribution statement; later per-file authorship remains unknown |
| Documentation license | No open-content or software license assigned | Owner decides whether to grant a reuse license after rights review |
| Experiment claims | No numerical performance claims included | Reconcile status and evidence before making stronger claims |

No dataset redistribution decision is needed for this exact payload because no dataset is included. That exclusion does not resolve permissions for a different future release.

GitHub distinguishes public visibility from an open-source license; its terms also allow viewing and forking public repositories. Choosing no license is not a confidentiality control. [GitHub licensing guidance](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository)
